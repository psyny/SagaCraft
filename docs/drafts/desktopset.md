Here a stage set for displaying basically anything. But in an organize manner.

The goal here is have a space for the DM show the player documents, quick images, characters, items, etc.

So its a tray where the DM can pick add entities:
-character
-item
-document
-Image

If its a character, the can chose the template to display.
An item will have its own display mode here, surprise me.
A document will have the option to switch pages
An image is uploaded on the fly. Be careful to delete the image when the pice on the set is deleted, so we dont leak server storage space.

These can be arranged in the set automatically, like we do for the actors. But here order is not important, just layout and to fit them in a way we use up the space. Or manually by the DM.

Each entity can be resized, rotated, etc.
