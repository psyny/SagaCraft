Mobile Tokens:

Tokens have a border and will be the person in control player color (the border), If more than one person control and is player: the border is white. If not a player the border is black.
Custom will just have a name and piture the DM can upload on runtime. Bewere of these picture for ephemeral elements, we dont want to keep them in the server side after these elements are gone.
Mobile tokens should be easily grrable on the map (set and editor), and snap to the center of grid tiles. And htey should have a size option (how many tiles they occupy.)
