EFX menas enviroment effects. It can be sound, visual, etc.
Its a new concept in the app.

The goal: effects to help immersion... Meaning, mostly they will be displayed on stage.

Concept 1:  environment.

Landscape is composed of a background far layer, background near layer, and a foreground layer.
The background far can be proedural effects or non transparent images. Like the clouds, nebula, etc.
The background near layer can be transparent pngs or procedural effects, like mountains, buildings, etc.
The foreground can be procedural effects only.
They all are connected, the user can create how many envoriment they want based on their own images and the procedural options we give.

On stage set, we can have 4:
-EFX - Far Background
-EFX - Near Background
-EFX - Foreground
-EFX - Controls

This is the first time we will have optionl stage set that are actually connected. Because the active Enviroment is only one, but it changes the contents of these sets, if they are present.

The EFX meny on the top bar, like hte others, lets user build their Envirments (and in the future other EFXss).
